Architecture / Technology

Helios Consensus, engineered for parallelism.

A BFT-based proof-of-stake protocol with optimistic block pipelining — finality in 400ms, sustained throughput north of 120,000 TPS.

Consensus Flow

Four stages, sub-second finality.

Parallel Throughput

Sealevel-style parallel execution.

Veltrax's execution layer reads each transaction's access list ahead of dispatch, scheduling non-conflicting transactions across all available CPU cores.

Where serial chains process transactions one at a time, Veltrax runs thousands of disjoint state transitions concurrently — without sacrificing EVM compatibility.

Changelog

Every notable change we ship, in reverse chronological order. Follow along and never miss an SDK update.

⌗ RSS feed · /changelog.rss
v2.14.0 Active Nov 18, 2024

Edge SDK GA — sub-50ms evaluation globally

The Edge SDK is officially production-ready. Deploy your flag rules to 300+ Cloudflare PoPs with a single command. Includes drop-in support for Next.js middleware, Vercel Edge Functions, and Cloudflare Workers.

  • NEWEdge SDK 1.0 with TypeScript, Go, and Rust runtimes
  • IMPCold start reduced from 47ms → 8ms on Workers
  • FIXResolved cache invalidation race on rapid flag updates
v2.13.2 Nov 6, 2024

PagerDuty integration & richer alert payloads

Route flag-change events directly into PagerDuty services with severity routing rules. Alerts now include the actor, environment, and a diff of targeting rules.

  • NEWPagerDuty v3 events integration with two-way ack
  • IMPAlert payloads now include rule diffs and JSON snapshots
v2.13.0 Oct 24, 2024

Bulk flag import & CSV migration tooling

Migrating off LaunchDarkly or Unleash? Import thousands of flags, environments, and targeting rules in one shot using our new CLI command flexor migrate.

  • NEWCSV / JSON bulk import for flags and segments
  • NEWflexor migrate CLI subcommand
  • FIXPagination off-by-one in /v1/flags list endpoint
v2.12.4 Oct 10, 2024

Stats Engine v2 preview & SRM detection

Opt into the new Bayesian stats engine from your project settings. Automatic sample ratio mismatch detection now flags broken experiments before you read them.

  • NEWBayesian credible intervals on all experiment readouts
  • NEWAutomatic SRM detection with severity scoring
v2.12.0 Sep 28, 2024

Self-hosted Relay v1 — keep evaluation in your VPC

The Flexor Relay runs as a lightweight Go binary inside your infrastructure, caching flag definitions and serving evaluations with zero external network calls.

  • NEWRelay v1.0.0 with Docker, Helm, and systemd packages
  • IMPReduced control-plane bandwidth by 90% for large customers

REST API reference

A small, predictable HTTP API. Every endpoint also has a typed SDK wrapper.

Endpoints

https://api.flexor.dev
GET /v1/flags List all flags in the workspace
GET /v1/flags/:key Retrieve a single flag by key
POST /v1/evaluate Evaluate a flag for a given user context
POST /v1/flags Create a new flag
PATCH /v1/flags/:key Update targeting rules or rollout %
POST /v1/experiments Start an A/B or multivariate experiment
GET /v1/audit-logs Paginated audit trail of all changes
DEL /v1/flags/:key Archive a flag (soft delete)

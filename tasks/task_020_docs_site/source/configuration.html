Configuration

✎ Edit on GitHub

Configuring Quillforge. All settings can be set via quill.toml, environment variables, or a programmatic Config() object. Settings are resolved in that order, with environment variables overriding the file and explicit Python overriding both.

Resolution order
Defaults < quill.toml < QUILL_* env vars < Config(...) kwargs < CLI flags.

quill.toml

The canonical configuration source. Quillforge looks for quill.toml in the working directory, then walks parent directories until it reaches the repo root or a directory containing pyproject.toml.

quill.toml 
# Quillforge 2.4 — production profile
[broker]
url        = "redis://cache.internal:6379/2"
namespace  = "quillforge.prod"
ssl        = true

[workers]
concurrency      = 16
prefetch         = 4
graceful_timeout = 30.0
queues           = ["default", "etl", "reports"]

[scheduler]
tick_interval = 1.0
timezone      = "UTC"

[telemetry]
otlp_endpoint = "https://otel.acme.io:4318"
service_name  = "quillforge-prod"
log_level     = "INFO"

[experimental]
hot_reload = false

Options Reference

A complete list of options recognised by quill.toml. Keys use dotted paths to indicate TOML section nesting.

Key Type Default Description
broker.url str redis://localhost:6379 Connection URL for the message broker. Supports redis://, rediss://, and nats://.
broker.namespace str "quillforge" Key prefix used for all broker entries. Useful for sharing a Redis instance across environments.
broker.ssl bool false Enable TLS on the broker connection. Requires server-side certificates.
workers.concurrency int 8 Number of concurrent task coroutines per worker process.
workers.prefetch int 2 Tasks pulled from the broker per fetch cycle. Higher reduces latency but inflates memory.
workers.graceful_timeout float 15.0 Seconds the worker waits for in-flight tasks during shutdown before forced cancellation.
workers.queues list[str] ["default"] Queues this worker subscribes to. Tasks dispatched to other queues are ignored.
scheduler.tick_interval float 1.0 Seconds between scheduler evaluation cycles for cron and interval triggers.
scheduler.timezone str "UTC" IANA timezone applied to all cron expressions unless overridden per-trigger.
telemetry.otlp_endpoint str | None None OTLP/HTTP endpoint for traces, metrics, and logs. When unset, telemetry is exported to stdout.
telemetry.service_name str "quillforge" OpenTelemetry service.name resource attribute applied to all signals.
telemetry.log_level str "INFO" Root log level. One of DEBUG, INFO, WARNING, ERROR.
experimental.hot_reload bool false Watch quill.toml for changes and apply mutable settings without restart. See note below.

Environment Variables

Every TOML key has an equivalent environment variable. Names are derived by uppercasing the dotted path, replacing dots with underscores, and prefixing with QUILL_. Lists are comma-separated.

TOML key
Environment variable
broker.url
QUILL_BROKER_URL
broker.namespace
QUILL_BROKER_NAMESPACE
broker.ssl
QUILL_BROKER_SSL
workers.concurrency
QUILL_WORKERS_CONCURRENCY
workers.prefetch
QUILL_WORKERS_PREFETCH
workers.queues
QUILL_WORKERS_QUEUES
scheduler.timezone
QUILL_SCHEDULER_TIMEZONE
telemetry.otlp_endpoint
QUILL_TELEMETRY_OTLP_ENDPOINT
telemetry.log_level
QUILL_LOG_LEVEL
experimental.hot_reload
QUILL_EXPERIMENTAL_HOT_RELOAD
shell 
# Override broker and log level at runtime
export QUILL_BROKER_URL="rediss://cache.internal:6380/0"
export QUILL_WORKERS_CONCURRENCY=32
export QUILL_LOG_LEVEL="DEBUG"
quill run pipelines/invoices.py

Profiles

Profiles let you keep environment-specific overrides in a single file. Activate one via --profile on the CLI or the QUILL_PROFILE env var.

quill.toml — profiles 
[profile.dev]
broker.url            = "redis://localhost:6379/0"
workers.concurrency   = 2
telemetry.log_level   = "DEBUG"

[profile.staging]
broker.url            = "redis://staging-cache:6379/1"
workers.concurrency   = 8

[profile.prod]
broker.url            = "rediss://cache.internal:6380/0"
broker.ssl            = true
workers.concurrency   = 16
telemetry.otlp_endpoint = "https://otel.acme.io:4318"

Selecting a profile

shell
quill run pipelines/etl.py --profile staging
# or
export QUILL_PROFILE=prod && quill worker

Advanced Patterns

Dynamic configuration with Vault

For secrets like broker credentials and TLS keys, prefer a secret manager over committing values to quill.toml. Quillforge ships a Vault loader that resolves vault:// URIs at startup:

python
from quill import Config
from quill.secrets import VaultResolver

cfg = Config.from_file(
    "quill.toml",
    resolvers=[VaultResolver(addr="https://vault.acme.io")],
)
# Any value of the form vault://secret/data/quill#field is resolved.

Programmatic overrides

You can construct Config entirely in code, which is convenient for tests and notebooks.

python
from quill import Config, Pipeline

cfg = Config(
    broker_url="memory://",
    workers_concurrency=1,
    telemetry_log_level="WARNING",
)
pipeline = Pipeline([load_csv, clean_rows], config=cfg)
Note — Hot reload
When experimental.hot_reload = true, Quillforge watches quill.toml with watchfiles and re-applies mutable settings (log level, queues, telemetry endpoint) without restarting workers. Immutable settings such as broker.url still require a restart.
Warning — Environment shadowing
A stray QUILL_BROKER_URL in your shell will silently override the profile selected with --profile prod. Use quill config print to inspect the effective configuration before deploying.
Danger — Secrets in TOML
Never commit broker passwords, TLS private keys, or OTLP auth headers to quill.toml in version control. Use vault:// references or QUILL_* env vars sourced from your secret manager.

Inspecting effective config

shell
$ quill config print --profile prod
broker.url            = "rediss://cache.internal:6380/0"     # env
broker.ssl            = true                                  # profile.prod
workers.concurrency   = 16                                    # profile.prod
workers.queues        = ["default", "etl"]                  # default
telemetry.otlp_endpoint = "https://otel.acme.io:4318"        # profile.prod
telemetry.log_level   = "INFO"                                # default

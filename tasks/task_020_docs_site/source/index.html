Quillforge 2.4 Documentation

Build resilient async task pipelines in pure Python. Stable release: 2.4.1 (Oct 2023).

Quillforge is a lightweight, async-first task orchestration framework for Python. Define tasks with a single decorator, compose them into pipelines, and run them on a fleet of distributed workers — all without leaving idiomatic asyncio.

Installation ¶

pip

Quick Example ¶

A minimal pipeline that fetches a list of users, transforms them, and writes the result. Save as demo.py and run with python demo.py.

# demo.py — your first Quillforge pipeline import quill from quill import Pipeline, TaskContext @quill.task(retries=3, timeout=10.0) async def fetch_users(ctx: TaskContext) -> list[dict]: async with ctx.http.get("https://api.example.com/users") as r: return await r.json() @quill.task async def enrich(users: list[dict]) -> list[dict]: return [{**u, "active": True} for u in users] pipeline = Pipeline([fetch_users, enrich], name="users-etl") if __name__ == "__main__": quill.run(pipeline.run(), workers=4)
📘 Note   Quillforge infers the DAG from the type signatures of your tasks — no manual wiring required. See DAG inference for details.

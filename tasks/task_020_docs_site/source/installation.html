Installation Guide

This guide walks you through installing Quillforge 2.4.1 on Linux, macOS, and Windows. Choose the section matching your platform, or jump straight to the virtual environment setup if you already have Python.

Prerequisites

Before installing Quillforge, make sure your system meets the following requirements:

  • Python ≥ 3.10 — CPython or PyPy 7.3+ supported. Python 3.11 recommended for best performance.
  • pip ≥ 23.0 — older versions will not resolve the quillforge[redis,otel] extras correctly.
  • Redis 7.x (optional) — required only when running the distributed worker pool.
  • Docker 24+ (optional) — for spinning up the quillforge/devcontainer stack.
  • ~150 MB free disk space for the runtime, plus extras for telemetry exporters.

Linux / macOS

Ubuntu 22.04
macOS 13 Ventura
Arch / Fedora

🐧 Ubuntu 22.04 LTS

Install Python and the venv module via apt, then install Quillforge with pip:

shell
$ sudo apt update
$ sudo apt install python3.11 python3.11-venv python3-pip
$ python3.11 -m pip install --upgrade pip
$ python3.11 -m pip install quillforge

🍎 macOS 13 Ventura (Homebrew)

The fastest path on macOS is the quillforge Homebrew formula, which bundles Python 3.11 and Redis as optional dependencies:

shell
$ brew tap quillforge/tap
$ brew install quillforge
$ brew services start redis  # optional, distributed mode

Windows 11

🪟 Windows 11 (PowerShell)

Install Python from the Microsoft Store or python.org, then run in an elevated PowerShell:

powershell
PS> winget install Python.Python.3.11
PS> py -3.11 -m pip install --upgrade pip
PS> py -3.11 -m pip install quillforge[redis,otel]
📝 Note — WSL2 recommended

For the distributed worker mode on Windows, we strongly recommend running Quillforge inside WSL2 with an Ubuntu 22.04 distribution. Native Windows is fully supported for the in-process scheduler only.

Virtual Environments

We strongly recommend installing Quillforge into an isolated virtual environment, especially when working on multiple projects. The standard venv module is sufficient:

shell — create & activate
$ python -m venv .venv && source .venv/bin/activate
(.venv) $ pip install --upgrade pip
(.venv) $ pip install "quillforge[redis,otel]"

The [redis,otel] extras pull in redis>=5.0, opentelemetry-sdk, and the OTLP/gRPC exporter. For a minimal install, drop the brackets.

Using Poetry or PDM

shell
$ poetry add "quillforge@^2.4" --extras "redis otel"
$ pdm add quillforge[redis,otel]

Verification

Confirm the installation by running the quill CLI. You should see output similar to the following:

terminal — verify
(.venv) $ quill --version
Quillforge 2.4.1 (CPython 3.11.5)
(.venv) $ quill doctor
✔ python                 3.11.5
✔ pip                    23.2.1
✔ quillforge             2.4.1
✔ redis client           5.0.1   (server unreachable — ok in local mode)
✔ otel-sdk               1.21.0
All checks passed. You are ready to quill init.

If quill --version reports a different version, your shell may be resolving an older binary on $PATH. Deactivate other environments and try again from a fresh shell.

Troubleshooting

✓ Note — Apple Silicon wheels

Native arm64 wheels are published for M1, M2, and M3 Macs on Python 3.10–3.12. No Rosetta required. The uvloop dependency is built against the macOS 13 SDK; older macOS versions will fall back to the asyncio default loop automatically.

⚠ Warning — Python 3.9 reached end-of-life

Quillforge 2.4 still installs on Python 3.9, but support is deprecated and will be removed in version 2.6 (Q2 2024). Upstream Python 3.9 security patches end October 2025. Plan an upgrade to 3.11 or 3.12 now.

⛔ Danger — Do not mix system pip with your venv

Running sudo pip install quillforge after activating a virtualenv will install the package into /usr/lib/python3, leaving your venv shadowed by a stale system copy. This is a common source of "ModuleNotFoundError: No module named 'quill.core'" reports. Always install inside the activated venv, without sudo.

Common errors

  • error: Microsoft Visual C++ 14.0 or greater is required — install the Build Tools for Visual Studio on Windows, then re-run pip.
  • SSL: CERTIFICATE_VERIFY_FAILED on macOS — run /Applications/Python\ 3.11/Install\ Certificates.command.
  • quill: command not found — your venv is not activated, or ~/.local/bin is missing from $PATH.

API Reference — quill.core

✎ Edit on GitHub

The quill.core module exposes the primitives every Quillforge program is built from: the @quill.task decorator, the Pipeline class, and the TaskContext object passed into each task at runtime. This page documents every public symbol with a stable contract.

quill.core

Core decorators, Pipeline class, and TaskContext primitives.

quill.task — decorator

Marks an async function as a Quillforge task. The decorated coroutine is registered with the currently active Registry and gains retry, timeout, and tracing behaviour configured by the decorator arguments.

function # quill.task(*, retries: int = 0, timeout: float | None = None, name: str | None = None) → Callable

Parameters

Name Type Required Default Description
retries int no 0 Maximum number of times the task will be re-invoked on failure. Uses exponential backoff with the policy from quill.toml.
timeout float | None no None Per-attempt timeout in seconds. When exceeded, asyncio.CancelledError is raised inside the task and the attempt is counted toward retries.
name str | None no fn.__name__ Override the registered task name. Useful when wrapping the same function multiple times or to keep a stable identifier across refactors.

Returns

Callable[[Coroutine], Task] A decorated coroutine function registered with the active quill.core.Registry. Calling the returned object inside a Pipeline queues an invocation; calling it outside a pipeline executes inline for testing.

Example

python · tasks/invoices.py 
from uuid import UUID
import quill

@quill.task(retries=5, timeout=12.0)
async def fetch_invoice(id: UUID) -> dict:
    # Network calls inside a task are automatically traced
    async with httpx.AsyncClient() as client:
        resp = await client.get(f"https://api.billing.test/v1/invoices/{id}")
        resp.raise_for_status()
        return resp.json()
⚠ Deprecated
quill.legacy_task is deprecated since 2.3 and scheduled for removal in 3.0. New code should use @quill.task. See the migration guide: legacy_task → task for an automated codemod.

Pipeline — class

Composes a sequence (or DAG) of tasks into a single executable unit. Pipelines are immutable once constructed and can be serialized to JSON for remote execution by a worker pool.

class # class quill.Pipeline(tasks: Sequence[Task], *, name: str | None = None, on_error: Literal["abort","continue"] = "abort")

Parameters

Name Type Required Default Description
tasks Sequence[Task] yes — An ordered sequence of @quill.task-decorated callables. DAG edges are inferred from the type signatures of each task's parameters and return type.
name str | None no None Human-friendly identifier surfaced in metrics, traces, and the quill ps CLI.
on_error Literal["abort","continue"] no "abort" Whether downstream tasks should still execute after an upstream failure. Use "continue" for fan-out workloads with isolated branches.

Methods

Signature Description
async run(*args, **kwargs) → Result Executes the pipeline on the current event loop. Returns a Result with per-task durations, outputs, and a trace ID.
submit(broker: Broker) → JobHandle Hands the pipeline off to a distributed broker (Redis or NATS). Returns immediately with a handle suitable for polling.
to_dot() → str Renders the inferred DAG as Graphviz DOT for documentation or debugging.

Returns

Pipeline A new pipeline instance. Pipelines are hashable and may be cached at module scope.

Example

python · pipelines/billing.py 
from quill import Pipeline
from tasks.invoices import fetch_invoice, normalize, write_warehouse

billing = Pipeline(
    [fetch_invoice, normalize, write_warehouse],
    name="billing.nightly",
    on_error="abort",
)

async def main():
    result = await billing.run(id="7f3a-…-9c01")
    print(result.summary())  # > 3/3 tasks ok in 1.82s

TaskContext — class

Runtime metadata injected into every task. Access it via the contextvar quill.current_context() from anywhere inside a task body.

class # class quill.TaskContext( task_id: str, attempt: int, trace_id: str, logger: structlog.BoundLogger)

Attributes

NameTypeDescription
task_id str ULID assigned at scheduling time. Stable across retries.
attempt int 1-indexed attempt number. Equals 1 on first run.
trace_id str W3C traceparent for OpenTelemetry correlation across services.
logger structlog.BoundLogger Pre-bound logger with task, attempt, and trace_id fields.
✓ Note
TaskContext is read-only. If you need to share mutable state between tasks, use quill.runtime.State instead — it is broker-backed and survives worker restarts.
✕ Danger
Never capture a TaskContext in a closure that outlives the task body. The bound logger holds a reference to the worker's connection pool and will leak file descriptors if retained across pipeline boundaries.
